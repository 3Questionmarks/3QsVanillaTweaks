# 3QsVanillaTweaks

A configurable collection of tweaks to vanilla Risk of Rain 2 items, focused on improving underused mechanics and making certain items more useful, particularly in multiplayer.

Each tweak can be individually enabled or disabled through the BepInEx configuration file.

**Current version: 0.0.1 — Experimental Release**

## Features

### Regenerating Scrap

Regenerating Scrap can now be used with additional 3D Printer rarities, rather than being restricted to Uncommon Printers.

- Common Printers — Enabled by default
- Uncommon Printers — Enabled by default
- Legendary Printers — Disabled by default
- Boss Printers — Disabled by default

### Dio's Best Friend

Consumed copies of Dio's Best Friend now regenerate at the beginning of each new stage, allowing the item to provide multiple revives throughout a run.

### Pluripotent Larva

Consumed copies of Pluripotent Larva now regenerate at the beginning of each new stage.

## Multiplayer

The mod is intended for multiplayer use, but this initial release is experimental and multiplayer behaviour is still being tested.

All players should use matching configuration settings (will be host settings sues when I figure out how to do that).
